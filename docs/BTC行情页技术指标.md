## 二、均线与图例

- **图例就是入口**：走势图左上角那行 = `币种 + 均线数值 + 涨跌 + 量`。
  开/高/低/收四项已去掉，空出来的位置留给均线读数，不再有「均线 ▾」下拉。
- 均线读数按添加顺序一行排开：`MA5 80,xxx`；窄屏（≤760px）自动换行，按钮换到下一行。
- **隐藏的均线不消失**：数值照常显示，只是变淡 + 删除线（`is-off`），和编辑页里的隐藏样式一致。
- **点一条均线读数**：弹出编辑小页，可改周期、选颜色（12 色 + 自定义）、隐藏 / 显示、删除。
- **＋ 添加均线**：图例右侧的按钮，点开选 5/10/20/30/60/120 或自定义 2-250；
  被占用的周期置灰，最多 6 条。
- **删除**：编辑页「删除这条均线」，或右键 K 线上的均线（7px 内）直接删。
- 隐藏、颜色、周期都写进 `localStorage`。
- **手机上**图例只留 `币种 + 均线读数 + 涨跌`，成交量数值（量）不占地方（`.mob .lg-vol` 隐藏）。

## 四、下单、平仓与账户

- **方向条 + 一个「开仓」按钮**：下单区最上面是 `#FBF7EE` 底的圆角条（圆角 8px、高 38px），
  外壳比里面的选项大一圈：选项本身 30px 高、四边留 3px，选中块不贴胶囊边。
  里面 `↗ 看多`（红）/ `↘ 看空`（绿）；选中一侧整块填浅红（多）/
  加深一点的浅绿（空，`rgba(48,92,56,.2)`），另一侧淡到 50%；
  点一下、按住左右滑、键盘 ← → 都能切。
  最底下一个 `#7B6337` 棕金色的「开仓」按钮按选中的方向开仓
  （原来的「开仓 / 平仓」模式切换已去掉）。
- **按金额下单（USDT）**：输入框整行铺满，左边一个静态的「数量」小字、右边一个灰色的
  小一号 `USDT`（`数量   25000.00 USDT`，单位是单独的静态文字，不参与编辑、不用手动敲）；
  开仓时按当前价换算成 BTC（向下取到 6 位）再下单，提示里同时给出「已开仓 x BTC（y USDT）」。
- **金额框在上、百分比滑杆在下**：两行都铺满整行（框拉长、滑杆也拉长好拖）；
  滑杆 30px 高，横线 / 圆点居中，百分比气泡收在里面；
  25/50/75/100% 是「可用余额的比例」（`maxAmount() = cash / (1 + FEE)`，
  手续费含在这笔钱里，100% 一定下得出去）。
- **平仓就两个字「平仓」**：在持仓明细最下面一条，和「开仓」按钮同款、通栏满宽；
  点了按市价把所有持仓一次平掉，不再按比例 / 数量分批平；
  没有持仓时整块（明细 + 平仓）都不显示；手机上也只留这个按钮（逐笔持仓看底部大表）。
- **有持仓就锁方向**：手里有多单时「看空」置灰点不动，只能继续开多；有空单时反之。
  同方向再开一次会合并到同一笔（数量、保证金相加，开仓价按加权均价）。
  这样就不会出现多空同时持有的仓。
- **盈亏放大 10 倍**：`PNL_MULT = 10`，客户端浮动/平仓盈亏、云端平仓/强平一致；
  保证金/名义价值不变。
- **收益率口径**：持仓表里括号中的百分比 = `浮动盈亏 ÷ 开仓金额 × 100%`，
  而 `浮动盈亏 = (平仓价 − 开仓价) × 数量 × 10`、`开仓金额 = 开仓价 × 数量`，
  所以化简后就是 **`(平仓价 − 开仓价) ÷ 开仓价 × 10 × 100%`**（价格涨跌幅 × 10）。
  例：64,347.03 → 64,412.46，涨 0.10168% × 10 = **1.0168%**；
  开仓金额 503.53 U 时，绝对收益 = 503.53 × 1.0168% ≈ **5.12 U**。
- **账户五个指标**（总资产、可用余额、整体盈亏、当日单数、胜率）同一套单元格样式。
- **胜率口径**：`收益率（盈亏 ÷ 开仓金额）> 0.1%` 的平仓单数 ÷ 已平仓单数
  （`WIN_RATE_MIN = 0.001`）。小赚、打平、亏损都不算赢——比如盈亏 +0.04 U、
  收益率只有 0.008% 的那一笔不计数。
- **重置资金**：头像菜单 →「重置资金」→ 确认后现金回到 100,000，
  清空持仓和挂单；**成交记录、当日单数、胜率保留**；整体盈亏按新本金重新算（归零）。
- 平仓不再弹二次确认；登录/绑定手机/退出仍在头像菜单。

## 七、画线 / 擦除（铅笔 / 橡皮图标）

- 「画线」：点一下激活（右下角红点），在 K 线上拖动**自由画曲线**；
  松开后自动退出激活。
- **按住 Shift 拖动**：只画起点到终点的直线。
- 「擦除」：清空**当前设备**上的画线（另一台设备的线保留）。
- **Ctrl+Z / ⌘+Z**：撤销上一次画线或擦除；焦点在输入框里时不拦截。
- 线存 `(时间, 价格)` 点列，平移/缩放/切周期后仍钉在原位；覆盖层平时不吃鼠标事件。
- 端点像素位置用 `logicalToX()`：先取两根可见 K 线的 `timeToCoordinate` 标定每根多少像素，
  再线性外推（视野外的点也能算）。**不要**拿画线层整块宽度乘逻辑比例——右边还有价格轴，
  那 78px 不扣掉的话越靠右偏得越多（桌面端最右一根能偏 70-80px，看起来就是端点对错了 K 线）。
- **手机和电脑的画线分开显示**：每条线带设备标记（`dev: 'm'` 手机 / `dev: 'd'` 电脑）。
  手机上只画手机上画的线，电脑上只画电脑上画的线；云端同步仍是一份数据，
  另一台设备的线只是不渲染，不会被删掉（老数据没有标记，按电脑处理）。

## 八、图表外观

- 网格：只保留横向虚线，颜色 `#E7DCC3`，竖向网格线去掉。
- 去掉左下角的 TradingView 标识（`layout.attributionLogo: false`）。
- 成交量和 MACD 的显示/隐藏改到**右键菜单 →「副图」**；原来的两个图标按钮已删除。
- 主图/副图仍是两个 chart 实例，时间轴只画在副图，区间和十字线双向镜像。
- **两张图必须等宽**：右侧价格轴是按各自刻度文字（主图 `78,105.58`、副图 `-35.45`）算宽度的，
  默认会差十几二十像素，同一个时间点在两张图上的 x 不一样，竖直的十字线就会和 MACD 柱子错位。
  `syncPaneWidths()` 每次重绘时把两边的 `minimumWidth` 对齐到同一个值（取较宽的那个），
  实测对齐后同一个时间的 `mainX` 和 `macdX` 完全相等。

## 十四、手机端手势与全屏（2026-10-31）

- **手机识别**：检测到手机时给 `<html>` 挂 `mob` 类。横屏全屏后视口宽度会超过 760px，
  只靠媒体查询会退回桌面样式，所以手机专属样式按设备走。
- **右侧留白**：手机上去掉那条 78px 的透明价格轴（`rightPriceScale.visible = false`），

## 十五、自选行情条（右侧「自选」，手机同款）

- 位置：钉在右侧一列的**最下边缘**（`position: sticky; bottom: 0`），
  右侧一列内容超高时也贴着面板底边，不会被挤到屏幕外。
- 每行显示 **`DOGE/USDT` + 最新价 + 24h 涨跌幅**：计价币 `USDT` 跟在全名后面、
  用次级色（`.watch-row__quote`），不再像以前那样把 `DOGEUSDT` 整串再写一遍。
- 名称列吃掉剩余宽度（太长省略），价格列和涨跌幅列都**右对齐**，四行数字对齐成两列；
  价格和涨跌幅之间固定 8px 间距，行内不会挤在一起。
- 最新价来自 `/api/v3/ticker/24hr?symbols=[...]`（一次最多 100 个，缓存 60 秒）；
  BTC 直接用 WebSocket 实时价，秒级更新。
- 自选展开时，价格文字每秒对一次；其它币种每 12 秒强制刷新一次价格和涨跌幅。
- 小数位按币自身的价位定（`priceDigits`：≥10 两位、≥1 四位、再小 5-8 位），低价币不会显示成 `0.00`。

## 十六、仓位计算（持仓明细下面）

指标和算法照 zentrader（`E:\3-zentrader`）侧边栏底部那个「仓位计算」，
只是那边没有杠杆，这里补上。

| 项 | 说明 |
| --- | --- |
| 初始资金 (USDT) | 默认跟着顶部「总资产」（现金 + 占用保证金 + 浮动盈亏）每分钟刷新，标签上带「自动」；**也可以自己改**，当成一个纯计算器用（改过之后「自动」消失、不再跟随）。**手里有持仓时锁死成总资产、输入框只读**（虚线框），平仓后把手填的值还回来 |
| 单笔风险R (%) | 这一单最多亏掉初始资金的百分之几；**填一次就记住**（`huideng.trade.riskr`），刷新页面也不变，除非自己再改 |
| 止损距离 (%) | 入场价到止损价的距离，按百分比填；**每单都不一样，只有这一项要每次手填**（不记忆，默认 2%） |
| 仓位 (USDT) | `初始资金 × 单笔风险R ÷ 止损距离` |
| 杠杆 | `仓位 ÷ 初始资金`（这里不填杠杆倍数，直接由仓位倒推） |

- 三个数只要有一个为空 / 为 0 / 小于 0，仓位显示 `0`、杠杆显示 `--`，不会出现除零。
- 初始资金跟的是**总资产**而不是累计入金：开了仓、浮盈浮亏变化，仓位和杠杆都会跟着变。
- 初始资金清空并失焦后，会重新回到「跟总资产」。
- 单笔风险R 清空或填 0 时，失焦后自动退回记住的那个值，不会把 R 弄丢。
- 位置钉在右侧一列的下面：`margin-top: auto` 把它压到底部、留 18px 再往下才是「自选」；
  开仓后上面多出持仓明细、平仓后又消失，这块都**不会被推上推下**。
- 标题右边一行小字按当前价把仓位折成 BTC 数量（`≈ 1.539902 BTC`），
  可以换算成金额填进上面的输入框（金额 = BTC 数量 × 当前价）来开对应仓位；
  行情每跳一次跟着刷新（行情没连上时留空）。
- 矮屏（≤820px 高）只留三行数值和两格结果，公式那行收起，公式改放在两格的 `title` 上。
- 手机上下单区下面照样有这块（持仓明细列表隐藏，仓位计算保留）。
