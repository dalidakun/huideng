# 网页版「交易笔记」

交易练习页走势图**右下角悬浮**一个黑色圆形**笔记按钮** → 笔记子页面从右侧滑入，顶到页面最上方、左侧上下圆角、左边留一段走势图；也可以直接访问 `/notes/`（独立页）。

页面本身：整页铺满、只留几像素边距；左侧标题列表底色比右侧深一档（和工具栏同色，中间没有分割线），标题下面是**第一次建立时间**，右侧三点菜单（分享 / 删除）；列表右下角是小号黑色圆形 + 号新建（加号已加粗放大）。正文是 contenteditable 富文本，工具栏在标题上方，外面包一条浅色色块；工具栏依次是图片、无序、加粗、斜体、下划线、字号、字色、清除格式，没有「更多」、有序、链接和表情，保存按钮在色块外、与正文右边缘对齐。标题 18px、正文 **16px / 行距 1.75 / 两端对齐**；标题输入框有很浅的「输入标题……」提示，标题和正文之间有一条细分隔线；字数、建立时间和绿色对勾「已保存」在标题输入框末尾靠右。图片直接插在光标处，可点开大图；输入停止或持续编辑时**每分钟自动保存一次**。删除先进回收站浮层，分享会生成公开只读页和二维码。

## 入口与登录

| 位置 | 文件 |
| --- | --- |
| 交易页走势图右下角笔记按钮 | `site/index.html`（`#btnNotes`，悬浮在 `.chartwrap` 内） |
| 右侧滑入子页面 | `site/index.html`（`#notesSlide` + iframe）+ `site/assets/js/trade.js` |
| 笔记页 | `site/notes/index.html` + `site/assets/notes.css` + `site/assets/js/notes.js` |

未登录点笔记按钮会先弹登录框，登录成功后自动滑出笔记子页面；头像菜单里不再放「交易笔记」。独立页 `/notes/` 未登录时点「去登录」会带 `?next=notes#login` 回首页，登录成功后回到笔记页。登录态复用行情页的会话 token，存在 `localStorage` 的 `huideng.trade.token`。交易页右上角默认用燃灯 App 图标头像。

头像菜单现在有：更换头像、更换手机号（未绑定则显示绑定）、同步交易记录、重置资金、退出登录。头像在浏览器里裁成 96×96 JPEG（约 1–2KB）后存 `tradeProfiles`，不占云存储；更换手机号验证新号码后会自动解绑旧号码；「同步交易记录」就是原来的同步账户数据。

## 数据与接口

笔记单独存 `tradeNotes` 集合，**不和 App 的 `userNotes` 混用**：App 同步时用 `set()` 整篇覆盖，混用会把 `images` 冲掉。

一条笔记一个文档：

```js
{
  _id, ownerUserId, title,
  content, contentFormat: "html",  // 服务端白名单清洗后的富文本
  lineHeight, preview,             // 固定 1.75（字段保留兼容）、列表预览纯文字
  images: [{ fileId, size }],      // 正文里 <img data-file-id> 的顺序，数量不设上限
  imageBytes, imageCount,          // 图片总字节/张数，聚合用量用
  shareId, sharedAt,               // 分享页 /note.html?s=<shareId>
  createdAt, updatedAt, deletedAt  // deletedAt > 0 表示在回收站
}
```

列表按 **createdAt** 倒序：编辑旧笔记不会改时间、不会挪位置。`deletedAt` 是软删除时间；恢复置 0，彻底删除才移除文档和图片。

老笔记没有 `contentFormat` 时按纯文字渲染（`textContent`），下一次保存会自动转成 HTML。正文只允许 `p/br/div/span/b/strong/i/em/u/s/strike/ul/ol/li/blockquote/h1-h3/a/img`；`a` 只放行 `http(s)`，`img` 只认本人 `tradeNotes/<uid>/` 下的 `data-file-id`，`style` 只保留 `color/background-color/font-size/text-align/line-height`；`script/iframe/on*`、`javascript:` 和 `position` 等一律清掉。

云函数 `api`（`cloudfunctions/api/trade.js`）新增的动作，全部走 `tradeLogin` 发的 token：

| action | 说明 |
| --- | --- |
| `tradeNoteList` | 分页列表（`pageSize` / `offset`，默认 50 条）+ 真实总数与图片用量 |
| `tradeNoteGet` | 详情（HTML 正文 + 行距），正文里的图片换 2 小时临时链接 |
| `tradeNoteSave` | 新建/更新，清洗 HTML；移除的图片同步删云存储 |
| `tradeNoteDelete` | 软删除进回收站（不删图片） |
| `tradeNoteRestore` | 从回收站恢复 |
| `tradeNotePurge` | 彻底删除文档和图片 |
| `tradeNoteTrashList` | 回收站分页列表 |
| `tradeNoteShare` | 生成/复用 `shareId`，返回 `/note.html?s=...` |
| `tradeNotePublicGet` | 公开分享页读取（不需要登录） |
| `tradeNoteUpload` | 图片 base64 上传，只收 jpeg/png/webp，≤1.5MB |
| `tradeAvatarGet` / `tradeAvatarSet` | 头像缩略图（96px JPEG，存 `tradeProfiles`，默认用 App 图标） |

服务端校验：只认当前用户 `tradeNotes/<uid>/` 下的 fileID，拒绝 `..` 跨目录；**笔记条数、单篇图片数量都不设上限**，图片总量 300MB（回收站里的图片也计入，彻底删除才释放）。列表按 50 条一页、`offset` 翻页，列表底部有「加载更多」。

## 图片为什么便宜

浏览器先压缩再上传：长边 ≤1600px、质量从 0.72 往下降到 ≤320KB（必要时再缩边）。手机截图通常 150–300KB，只有原图的 1/15 左右。

按 2026 年 11 月 CloudBase 资源点价（1,000 点 ≈ 1 元）：

- 标准存储 0.004 元/GB/天 ≈ **0.12 元/GB/月**
- 云存储 CDN 流量 **0.21 元/GB**（未命中缓存另加 0.15 元/GB 回源）
- 读写请求 0.01 元/万次

1,000 人、每人每月 6 张压缩图的量级约 **3 元/月**；1 万人约 **30 元/月**。原图直传（4MB/张）成本约 ×16，所以压缩这一步不要省。

## 自动保存的成本

自动保存只写同一条文档（HTML 正文），**不重复上传图片、不增加存储**；每次保存多一次更新、一次计数和一次聚合用量查询。

自动保存是「每分钟最多一次」：从第一次改动开始计时，一分钟内持续输入不会重复提交；保存过程中又有改动，会保留改动并在下一分钟再存。

按 1,000 个活跃用户估算：

| 每天实际写作时长 | 月保存次数 | 月成本 |
| --- | --- | --- |
| 10 分钟 | 30 万次 | 约 15–25 元 |
| 20 分钟 | 60 万次 | 约 30–45 元 |
| 1 万人 × 20 分钟 | 600 万次 | 约 300–450 元 |

成本主要来自数据库读写，不是存储；图片成本不变。

## 部署

```powershell
# 云函数（在函数目录里执行，否则打 zip 会把整个仓库带上）
cd cloudfunctions/api
tcb fn code update api --dir . -e randeng-d8gs968w22a3d98e8 --deployMode zip

# 静态站
cd ..\..
python tools\build_site.py --sync
tcb hosting deploy site/dist -e randeng-d8gs968w22a3d98e8 --ignore "downloads/**"
```

首页/笔记页这类入口文件建议单独再传一次（`tcb hosting deploy site/dist/index.html index.html -e ...`），批量上传失败时它们最容易被跳过。

## 已知取舍

- 上传成功但没保存的图片会成为孤儿文件，目前没有自动清理；300MB 配额按笔记里实际引用的图片统计，不包含孤儿。
- 笔记条数、单篇图片数量不设上限，数据库按条增长；文字笔记单条约 2KB，1 万条约 20MB，量级很小。
- 回收站里的图片仍占云存储，也计入 300MB；只有「彻底删除」才释放。
- 分享链接公开只读，拿到链接的人都能看；内容跟笔记实时同步（不是快照），删除/进回收站后链接失效。
- 列表用 `offset` 翻页；翻页期间如果在别的设备新增/删除笔记，理论上可能漏一条或重复一条，前端按 `noteId` 去重，影响很小。
- 图片走 2 小时临时链接，笔记页开太久后点开大图可能过期；重新进笔记会刷新链接。
- 头像存 96px JPEG 缩略图（约 5KB/人），默认用 App 图标；App 内暂不显示网页头像。
- 笔记只存在网页端，App 的「我的笔记」暂时看不到；要互通得再改 Flutter 端的笔记模型和渲染。
