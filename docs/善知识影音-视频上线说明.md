## 二、加一部新视频（一条命令）

把新视频放进 `master\`，然后在本仓库根目录执行：

```powershell
node tools\publish_video.mjs --id v002 --title "金刚经" --master "E:\9-huideng-video\master\v002.mp4" --desc "一句话简介"
```

脚本会依次做：

1. `ffprobe` 读时长/分辨率；
2. 转 **720P H.264 + AAC**（压缩成手机能硬解的 MP4，`+faststart`）；
3. 截一张封面（默认第 300 秒，可加 `--at 120` 指定）；
4. 切成 **6 秒一片的 HLS**（TS 切片）；
5. 逐片传到 R2，合并并上传 `catalog.json`；
6. 打印封面 / 播放 / 清单三个地址。

已经生成过的中间文件会跳过，中断后重跑即可续传（脚本会先列出云端已有的对象）。

## 三、为什么用 HLS 而不是一个大 MP4

`wrangler r2 object put` **单文件上限 300 MiB**，而 v001 压完是 403 MiB。两个选择：

1. 让 wrangler 直接传：不行，会报 `Wrangler only supports uploading files up to 300 MiB`；
2. **切成 HLS 小片**：每片 1 MB 左右，逐片走 Cloudflare REST API 上传。

HLS 还有额外好处：起播快、拖动只拉附近几片。
**按你的要求只做原分辨率一档**（不做 480P/360P 多码率），存储最省：
v001 一档 420MB，10GB 约 24 部；超出的存储费约 0.11 元/GB/月，出流量不收费。

## 四、App 端代码

| 文件 | 作用 |
| --- | --- |
| `lib/video_catalog.dart` | 视频/清单模型、R2 根地址、缓存与兜底清单 |
| `lib/shanzhishi_video_page.dart` | 善知识菜单页（大卡 + 简介 + 列表） |
| `lib/video_player_page.dart` | 播放页（控制层 / 倍速 / 全屏 / 续播） |
| `lib/main.dart` | 底部菜单第 4 格由空白页换成 `ShanZhiShiVideoPage` |

App 拉清单的顺序：本地缓存 → 云端 `catalog.json`（10 秒超时）→ 内置兜底清单。
所以断网时页面不会空白，v001 也照样能播（只要有网）。

改 R2 域名只需改 `lib/video_catalog.dart` 里的 `kVideoBaseUrl`。

## 五、注意事项

- **r2.dev 是开发调试域名**，Cloudflare 会对它限速，国内访问速度一般。正式上线建议在
  R2 里绑定自定义域名（如 `video.你的域名.com`），把 `kVideoBaseUrl` 换掉即可；
  自定义域名需要先把域名 NS 迁到 Cloudflare。
- 视频片必须带 `Cache-Control: public, max-age=31536000, immutable`（脚本已带），
  清单用 `max-age=60`，加片后最多一分钟生效。
- iOS / 安卓都支持 HLS；但 **Flutter Web 的 `video_player` 不支持 HLS**。
  本 App 是安卓端（`minSdk 21+`），不受影响；以后要做网页版再补 MP4/HLS.js。
- 播放页会保持屏幕常亮（`wakelock_plus`），退出自动恢复；进度存在本地
  `video_pos_<id>`，下次接着看。
- 如果 `flutter build apk --release` 报 `GeneratedPluginRegistrant.java` 找不到
  `FlutterNativeSplashPlugin` / `IntegrationTestPlugin`：这是先跑过 debug/test 后
  注册文件里残留了 dev 插件。`flutter clean` 后重新构建即可（release 会自动排除
  dev 插件）。

## 六、网盘直链模式（先下载、再本地播放）

面向国内不挂 VPN 的方案：视频放**光鸭云盘**等网盘，App 用直链下载到手机，再用
内置播放器播本地文件。

**清单字段**（`catalog.json` 的某部视频）：

```json
{
  "id": "v001",
  "title": "佛说无量寿经",
  "downloadUrl": "https://光鸭直链/v001.mp4",
  "fileSize": 403000000
}
```

- `downloadUrl` 有值 → 走「下载后本地播放」；为空 → 退回原来的 R2 HLS 在线播放；
- `fileSize` 用于进度条和空间提示，可不填；
- 换网盘/换链接只改清单，**不用发新版**。

**App 行为**（`lib/video_download_store.dart` + `lib/video_player_page.dart`）：

- 列表页**没有下载按钮**；点封面进播放页；
- 本地没有文件 → 自动下载（进度条、速度、剩余时间、可取消）；
- 下载完自动播放本地文件，下次打开秒开；
- 支持断点续传（`.part` 文件 + HTTP Range），退出再进接着下；
- 文件存 App 私有目录 `videos/<id>.mp4`，不需要存储权限。

**注意**：

- 下载期间 App 要保持前台，息屏可能被系统挂起；
- 网盘直链如果带签名/有效期，过期后要在 `catalog.json` 里换新链接；
- 网盘公开分发视频要遵守其服务条款与版权要求。

### 分片（绕开网盘 100MB 单文件限制）

蓝奏云等网盘免费版单文件限 100MB，把 MP4 按字节切成 <90MB 的分片即可：

```powershell
node tools\split_video_parts.mjs --file "E:\9-huideng-video\dist\v001-720p.mp4" --id v001
```

v001 会切成 4×90MB + 1×42.8MB，共 5 片。把 5 片分别上传网盘、拿到直链后，
在 `catalog.json` 里写 `parts`：

```json
"parts": [
  { "url": "https://…/part-001.mp4", "size": 94371840 },
  { "url": "https://…/part-002.mp4", "size": 94371840 },
  { "url": "https://…/part-003.mp4", "size": 94371840 },
  { "url": "https://…/part-004.mp4", "size": 94371840 },
  { "url": "https://…/part-005.mp4", "size": 44879872 }
]
```

App 会逐片下载（每片可单独续传），全部完成后按顺序拼成一个 MP4、校验总大小，
再删除分片。`size` 用于校验，必须与实际文件一致。
